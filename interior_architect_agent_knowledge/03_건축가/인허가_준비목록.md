# 인허가 준비 목록

> 건축 허가/신고는 지역 조례에 따라 다를 수 있습니다. 최종 확인은 관할 구청 건축과에 문의하세요.

---

## 건축 허가 vs 신고 구분 기준

| 구분 | 기준 | 처리 기간 |
|------|------|----------|
| **건축 허가** | 연면적 100㎡ 초과 (도시지역) | 15~30일 |
| **건축 신고** | 연면적 100㎡ 이하 (도시지역) | 5~7일 |
| | 85㎡ 이하 단독주택 증축 | |
| **대수선** | 주요 구조부 변경 | 허가 기준 |
| **리모델링** | 증축 없는 내부 공사 | 신고 기준 |

> 비도시지역(농지, 산지)은 별도 기준 적용. 산지는 산림청, 농지는 농업위원회 협의 필요.
