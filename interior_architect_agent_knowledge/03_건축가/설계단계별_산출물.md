# 설계 단계별 산출물 (국토교통부 건축사 업무범위 기준)

---

## 1. 기획업무

### 목적
건축물의 건립 가능 여부 및 사업 방향을 결정하기 위한 기초 검토

### 주요 산출물
| 산출물 | 내용 | 비고 |
|--------|------|------|
| 대지 분석 보고서 | 용도지역/지구, 법규 검토, 건폐율/용적률 분석 | |
| 개략 사업성 검토 | 연면적, 세대수/실수, 개략 사업비 | |
| 기본 구상안 | 배치 방향, 규모, 개념 다이어그램 | |
| 인허가 사전 검토 | 담당 구청 사전 상담 결과 | |
| 사업 추진 일정 | 설계-인허가-착공-준공 예상 일정 | |

### 수집 자료
- 지적도, 토지이용계획확인서
- 도시계획 현황도
- 지구단위계획서 (해당 시)
- 인근 건축물 현황

---

## 2. 계획설계

### 목적
건축물의 기본 방향을 결정하는 단계. 건축주 승인 필요.

### 주요 도면 산출물
| 도면 | 축척 | 내용 |
|------|------|------|
| 배치도 | 1/200~1/500 | 대지 내 건물 위치, 주차, 진입 동선 |
| 각 층 평면도 | 1/100~1/200 | 실 배치, 면적, 주요 치수 |
| 정/측/후면 입면도 | 1/100~1/200 | 외관, 재료 범례 |
| 주요 단면도 | 1/100 | 층고, 레벨 관계 |
| 투시도/조감도 | - | 건축물 외관 이미지 |
| 3D 모델 | - | 검토용 매스 모델 |

### 주요 설명 문서
- 설계 설명서 (컨셉, 배치 이유, 재료 방향)
- 개략 면적표
- 개략 공사비 추정

---

## 3. 중간설계 (기본설계)

### 목적
구조, 설비, 재료를 구체화하여 실시설계의 기초를 마련

### 주요 도면 산출물
| 도면 | 축척 | 내용 |
|------|------|------|
| 평면도 (전층) | 1/100 | 실명, 면적, 마감 범례 포함 |
| 입면도 (전면) | 1/100 | 재료, 색상, 창호 위치 |
| 단면도 | 1/100 | 구조 관계, 층고, 개구부 |
| 천장 평면도 | 1/100 | 조명, 설비 위치 |
| 창호 일람표 | - | 창호 종류, 규격, 개폐 방식 |
| 실내 마감표 | - | 공간별 바닥/벽/천장 마감 |
| 구조 기본 계획 | 1/100 | 기둥, 보, 슬래브 시스템 |
| 설비 기본 계획 | 1/100 | 기계/전기/소방 시스템 개요 |

### 주요 설명 문서
- 구조 설계 방침서
- 설비 시스템 방침서
- 재료 선정 기준
- 에너지 절약 계획서 (초안)

---

## 4. 실시설계

### 목적
시공이 가능한 수준의 상세 도면 및 시방서 작성. 인허가 제출 도면 포함.

### 건축 도면
| 도면 | 내용 |
|------|------|
| 배치도 | 공사 범위, 경계, 주차, 조경 |
| 평면도 (전층) | 벽체 두께, 치수, 개구부, 마감 |
| 입면도 (4면) | 재료, 높이, 창호 상세 |
| 단면도 | 구조, 단열, 마감 상세 |
| 지붕 평면도 | 방수, 배수, 단열 |
| 천장 평면도 | 조명, 설비, 천장 마감 |
| 창호 상세도 | 창호 단면, 실리콘, 단열 |
| 계단/엘리베이터 상세 | |
| 화장실 상세도 | 방수, 타일, 위생기구 배치 |
| 주요 부위 상세도 | 지붕, 외벽, 바닥 상세 |
| 실내 전개도 | 주요 실 4면 마감 표현 |

### 구조 도면
| 도면 | 내용 |
|------|------|
| 기초 평면도 | 기초 형식, 크기, 배근 |
| 각층 구조 평면도 | 기둥, 보, 슬래브 위치 |
| 배근 상세도 | 주요 접합부 배근 |
| 구조 계산서 | 하중, 응력, 변형 계산 |

### 설비 도면
| 도면 | 내용 |
|------|------|
| 급배수 평면도 | 배관 경로, 사이즈 |
| 난방 평면도 | 난방 배관, 분배기 위치 |
| 환기 평면도 | 덕트 경로, 기기 위치 |
| 전기 평면도 | 배선, 기구 위치, 분전함 |
| 조명 평면도 | 조명 기구 위치, 회로 |
| 소방 평면도 | 스프링클러, 감지기, 소화기 |

### 문서
| 문서 | 내용 |
|------|------|
| 공사시방서 | 각 공종별 시공 기준 |
| 수량산출서 | 공종별 자재 수량 |
| 내역서 | 공종별 공사비 세부 내역 |
| 에너지절약계획서 | 단열, 창호, 설비 성능 |
| 일조/일영 계획서 | 해당 시 |

## 5. 감리 업무

### 주요 기록
| 문서 | 내용 |
|------|------|
| 감리 일지 | 일별 현장 방문 기록 |
| 검측 기록부 | 공종별 검측 결과 |

| 준공 검측 기록 | 준공 전 최종 확인 |
| 사용승인 신청 서류 | 준공 사진, 검사 체크리스트 |
