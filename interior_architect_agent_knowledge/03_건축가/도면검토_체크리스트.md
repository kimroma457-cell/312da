## 도면 간 충돌 체크 포인트

| 충돌 유형 | 확인 방법 |
|-----------|----------|
| 평면도 ↔ 입면도 창호 크기 불일치 | 창호 기호 대조 |
| 구조 기둥 ↔ 평면 벽체 불일치 | 중첩 확인 |
| 천장도 조명 ↔ 전기도 회로 불일치 | 회로별 기구 대조 |
| 설비 배관 ↔ 구조 보 간섭 | BIM 또는 도면 중첩 |
| 계단 층고 ↔ 단면도 치수 불일치 | 단면도 확인 |
