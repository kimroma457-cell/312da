# 스펙북 생성 프롬프트

## 사용법

아래 프롬프트에 공간 정보, 스타일, 예산 등급을 입력하면 마감재 스펙북을 자동 생성합니다.

---

## 스펙북 생성 프롬프트 템플릿

```
당신은 10년 이상 경력의 인테리어 디자이너입니다.
아래 정보를 바탕으로 마감재 스펙북을 작성해 주세요.

[프로젝트 정보]
- 공간 유형: {아파트/빌라/상업공간}
- 전용면적: {평수}
- 공사 범위: {공간 목록}
- 디자인 스타일: {모던/내추럴/북유럽/클래식 등}
- 예산 등급: {보급형/중급/고급}
- 색상 방향: {화이트 계열/그레이 계열/우드톤 등}
- 특별 요청: {있으면 기재}

## 스펙북 출력 형식

각 공간별로 아래 형식으로 작성해 주세요:

### [공간명]

#### 바닥재
| 위치 | 자재명 | 브랜드 | 품번 | 규격 | 색상 | 단가(㎡) | 수량(㎡) | 금액 |
|------|--------|--------|------|------|------|----------|----------|------|
| | | | | | | | | |

#### 벽 마감
| 위치 | 자재명 | 브랜드 | 품번 | 색상/패턴 | 단가 | 수량 | 금액 |
|------|--------|--------|------|----------|------|------|------|
| | | | | | | | |

#### 천장
| 자재명 | 색상 | 처리 방법 | 비고 |
|--------|------|----------|------|
| | | | |

#### 조명
| 위치 | 기구명 | 브랜드 | 규격 | 색온도 | 수량 | 단가 | 금액 |
|------|--------|--------|------|--------|------|------|------|
| | | | | | | | |

#### 특이사항
- 시공 주의사항:
- 대체 자재 옵션:
- 발주 시 주의사항:

---

### 전체 자재 발주표

| 공간 | 자재 | 브랜드/품번 | 수량 | 단가 | 금액 | 납기 | 발주처 |
|------|------|------------|------|------|------|------|--------|
| | | | | | | | |
| **합계** | | | | | | | |
```

## 빠른 스펙북 프롬프트 (핵심만)

```
{스타일: 모던 미니멀} {예산: 중급} {면적: 30평} 아파트 전체 리모델링을 위한
바닥재, 벽 마감, 조명, 욕실 타일 스펙북을 표 형식으로 만들어줘.
브랜드와 단가도 포함해줘.
```

---

## 스펙북 검토 프롬프트 (기존 스펙북 검토)

```
다음 스펙북을 검토하고 문제점을 찾아줘:

{스펙북 내용}

확인 항목:
1. 각 자재의 시공 위치가 명확한가?
2. 브랜드/품번이 구체적인가?
3. 수량 계산이 적절한가? (여분 10% 포함 여부)
4. 납기가 공정표와 맞는가?
5. 동일 공간에서 자재 간 색상/톤이 맞는가?
6. 빠진 자재가 있는가?
```
