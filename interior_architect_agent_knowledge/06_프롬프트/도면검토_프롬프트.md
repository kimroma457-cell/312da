# 도면 검토 프롬프트

## 사용법

도면 목록, 도면 설명, 또는 도면에서 읽은 텍스트를 입력하여 검토를 요청합니다.

---

## 도면 누락 검토 프롬프트

```
당신은 건축사 사무소에서 10년 이상 근무한 건축 설계 전문가입니다.
다음 도면 목록을 검토하고 누락된 도면이 있는지 확인해 주세요.

[프로젝트 정보]
- 용도: {주거/근린생활/사무소 등}
- 규모: {연면적, 층수}
- 설계 단계: {계획설계/중간설계/실시설계}
- 인허가 단계: {건축허가/신고}

[현재 보유 도면 목록]
{도면 목록 기재}

## 확인 항목
1. 필수 도면 중 누락된 것은?
2. 인허가 제출에 필요한 도면 중 빠진 것은?
3. 해당 설계 단계에서 필요한 도면이 갖춰졌는가?
```

---

## 도면 간 충돌 검토 프롬프트

```
다음 도면 내용을 바탕으로 도면 간 충돌 가능성을 검토해 주세요.

[평면도 정보]
{창호 위치, 벽체 위치, 실 배치 등}

[입면도 정보]
{창호 크기, 위치 등}

[천장도 정보]
{조명, 설비 위치 등}

[구조도 정보]
{기둥, 보 위치 등}

확인 항목:
1. 평면도와 입면도의 창호 위치·크기 일치 여부
2. 천장도 조명 위치와 전기도 회로 일치 여부
3. 구조 보와 설비 배관 간섭 가능성
4. 계단 치수와 단면도 층고 일치 여부
5. 기타 충돌 가능성
```

## 인테리어 도면 검토 프롬프트

```
당신은 인테리어 현장 경험이 풍부한 전문가입니다.
다음 인테리어 도면 정보를 검토해 주세요.

[도면 내용]
{평면도/천장도/입면도 등의 내용}

확인 항목:
1. 마감재 표기가 누락된 공간이 있는가?
2. 조명 위치와 스위치 위치가 적절한가?
3. 콘센트 위치가 가구 배치와 맞는가?
4. 욕실 방수 범위가 표시되어 있는가?
5. 문 개폐 방향이 동선에 문제가 없는가?
6. 창호 필름/커튼 박스 계획이 있는가?
7. 에어컨 실내기·배관 슬리브 위치가 있는가?
8. 분전함 위치가 적절한가?

결과를 표 형식으로 정리해 주세요.
```

```

{기호/약어 목록}

또는: 다음 도면 내용을 비전문가도 이해할 수 있게 설명해 주세요:
{도면 내용}
```
