# 견적 검토 프롬프트

## 사용법

아래 프롬프트를 LLM에 제공하고, [견적서 내용]에 실제 견적서를 붙여넣으세요.

---

## 견적 검토 프롬프트 템플릿

```
당신은 20년 경력의 인테리어 시공 전문가입니다.
아래 견적서를 검토하고 다음 항목을 분석해 주세요.

[견적서 내용]
{여기에 견적서 내용 붙여넣기}

[현장 정보]
- 공간 유형: {아파트/빌라/상업공간 등}
- 면적: {평수}
- 공사 범위: {전체/욕실/주방 등}

## 검토 요청 항목

### 1. 누락 공종 탐지
다음 공종 중 견적서에 없는 항목을 찾아주세요:
- 철거, 폐기물 처리, 양중비
- 목공 (천장/벽/가벽/문틀/몰딩)
- 전기 (배선/콘센트/스위치/조명기구/분전함)
- 설비 (급수/배수/난방/위생기구)
- 방수 (욕실/발코니)
- 타일 (재료비 + 시공비 구분 여부)
- 도장/벽지 (재료비 + 시공비)
- 바닥재 (재료비 + 시공비)
- 가구 (싱크대/붙박이장)
- 조명 기구
- 실리콘 마감
- 청소
- 기타 (걸레받이, 코너비드 등)

### 2. 단가 이상 여부
각 공종의 단가가 2024년 수도권 시장가와 비교해 크게 높거나 낮은 항목이 있으면 표시해 주세요.

### 3. 자재비/인건비 구분
자재비와 인건비가 분리되어 있나요? 분리되지 않은 경우 실행예산 관리가 어렵습니다.

### 4. 부가세 처리
부가세 포함/별도 여부가 명시되어 있나요?

### 5. 예비비
총 공사비의 5~10% 예비비가 포함되어 있나요?

### 6. 검토 결과 요약
| 항목 | 상태 | 비고 |
|------|------|------|
| 누락 공종 | | |
| 단가 이상 | | |
| 자재/인건비 구분 | | |
| 부가세 명시 | | |
| 예비비 | | |
| 전반적 평가 | | |
```

---

## 간단 체크 프롬프트 (빠른 검토용)

```
다음 견적서에서 누락된 공종과 이상한 단가가 있으면 알려줘.
공사 범위는 {공간/면적}이고, 수도권 기준이야.

{견적서 내용}
```

---

## 결과 예시

```
## 견적 검토 결과

### 누락 공종
- ❌ 폐기물 처리비 없음 → 철거 시 반드시 필요, 약 150~200만원 예상
- ❌ 양중비 없음 → 엘리베이터 사용 가능 여부 확인 필요
- ❌ 실리콘 공사 없음 → 욕실/주방 마감에 필수
- ❌ 준공 청소 없음 → 약 30~50만원 추가

### 단가 이상
- ⚠️ 타일 시공 (㎡당 20,000원) → 시장가 35,000~65,000원 대비 낮음, 저품질 우려
- ⚠️ 도장 공사 (벽 도장 ㎡당 5,000원) → 시장가 8,000~15,000원 대비 낮음

### 주의사항
- 자재비/인건비 미구분 → 실행예산 관리 어려움
- 부가세 포함 여부 불명확
- 예비비 미포함

### 최종 평가
현재 견적은 누락 공종과 낮은 단가로 인해 실제 공사 시 추가 비용 발생 가능성이 높습니다.
추정 추가 비용: 약 200~400만원 (폐기물, 양중, 실리콘, 청소 등)
```
