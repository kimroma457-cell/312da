# 건축사 업무범위 및 대가기준

> 국토교통부 고시 「건축사의 업무범위와 대가기준」 기반. 실제 계약 시 건축사와 협의 필요.

---

## 1. 건축사 업무 범위

### 설계 업무

| 단계 | 내용 |
|------|------|
| 기획업무 | 사업 기획, 법규 검토, 대지 분석, 개략 사업성 검토 |
| 계획설계 | 배치, 평면, 입면, 단면 계획, 개략 공사비 산정 |
| 중간설계 | 구조, 설비, 재료 구체화, 관련 법규 검토 |
| 실시설계 | 시공 도면 작성, 시방서, 수량 산출 |

### 감리 업무

| 업무 | 내용 |
|------|------|
| 공사감리 | 현장 방문, 시공 확인, 자재 검토 |
| 검측 | 공종별 검측, 기록 |
| 공사감리 보고서 | 감리 결과 보고 |

---

## 2. 설계 대가 산정 방식

### 2-1. 공사비 요율 방식

건축사 설계비 = 공사비 × 요율

| 공사비 구간 | 기본 요율 |
|-------------|----------|
| 1억 미만 | 12~15% |
| 1~3억 | 10~12% |
| 3~10억 | 8~10% |
| 10~30억 | 6~8% |
| 30억 이상 | 협의 |

> 소규모 건축물, 주거용 등은 요율 조정 가능

### 2-2. 단계별 대가 배분

| 단계 | 비율 |
|------|------|
| 기획업무 | 10~15% |
| 계획설계 | 20~25% |
| 중간설계 | 25~30% |
| 실시설계 | 35~40% |
| 감리 | 별도 산정 |

### 2-3. 감리 대가

감리비 = 공사비 × 감리 요율

| 공사비 구간 | 감리 요율 |
|-------------|----------|
| 1억 미만 | 5~8% |
| 1~5억 | 4~6% |
| 5~20억 | 3~5% |
| 20억 이상 | 협의 |

---

## 3. 계약 구조

### 일반적인 설계 계약 단계

```
설계 계약 체결
   ↓
계획설계 착수 → 계획설계 대가 청구 (계획설계 완료 시)
   ↓
건축주 승인
   ↓
중간설계 → 중간설계 대가 청구
   ↓
실시설계 → 실시설계 대가 청구 (인허가 신청 전)
   ↓
인허가 신청 및 허가
   ↓
감리 계약 별도 체결 (또는 설계 시 포함)
```

---

## 4. 추가 대가 발생 사유

| 항목 | 내용 |
|------|------|
| 설계 변경 (건축주 요청) | 협의에 의한 추가 대가 |
| 재설계 | 건축주 귀책 시 추가, 건축사 귀책 시 무상 |
| 인허가 보완 | 관청 요구 보완은 포함, 건축사 오류 보완은 무상 |
| 특수 용역 (구조, 설비, 소방) | 별도 계약 |
