# 주요 건축 법규 체크리스트

> 에이전트는 검토해야 할 항목을 안내합니다. 법규는 수시로 개정되므로 최종 판단은 건축사·관할 구청에서 확인하세요.

## 1. 건축법 기본 사항

| 항목 | 확인 내용 | 관련 조항 |
|------|-----------|----------|
| 용도지역 | 대지의 용도지역 확인 | 국토계획법 |
| 건폐율 | 건폐율 이내인지 | 건축법 55조 |

| 대지 접도 | 도로에 접하는지 (최소 4m) | 건축법 44조 |

## 2. 주차장법

| 항목 | 확인 내용 |
