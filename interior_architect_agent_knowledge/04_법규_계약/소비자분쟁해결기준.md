# 소비자분쟁해결기준 (실내건축 공사)

> 공정거래위원회 고시 기준. 2023년 12월 개정안 반영. 실제 분쟁 시 한국소비자원 확인 필요.

---

## 1. 하자 유형별 배상 기준

### 1-1. 시공 불량 하자

| 하자 내용 | 배상 기준 |
|-----------|----------|
| 방수 불량으로 인한 누수 | 재시공 + 피해액 배상 |
| 타일 들뜸/균열 | 재시공 (하자담보 기간 내 무상) |
| 도장 박리/변색 (1년 이내) | 재시공 (무상) |
| 마루 들뜸/단차 | 재시공 (무상) |
| 구조적 하자 | 재시공 + 피해액 배상 |

### 1-2. 자재 불일치

| 상황 | 배상 기준 |
|------|----------|
| 계약 자재와 다른 자재 사용 | 재시공 또는 차액 환급 |
| 품질 등급 미달 자재 사용 | 재시공 또는 차액 환급 |
| 하자 있는 자재 사용 | 재시공 + 공사 지연 배상 |

---

## 2. 공사 지연 배상

| 지연 원인 | 배상 기준 |
|-----------|----------|
| 시공사 귀책 지연 | 계약금액의 0.1%/일 |
| 자재 수급 문제 | 협의 (단, 시공사 발주 지연은 귀책) |
| 추가공사 합의 지연 | 발주자 귀책 시 배상 불요 |
| 천재지변 | 쌍방 무책임, 공기 연장 |

---

## 3. 계약 해제 시 정산

### 발주자(고객) 귀책으로 해제

| 시점 | 위약금 |
|------|--------|
| 착공 전 | 계약금의 10% |
| 공사 중 | 기시공 부분 정산 + 손해배상 |

### 수급인(시공사) 귀책으로 해제

| 시점 | 위약금 |
|------|--------|
| 착공 전 | 계약금 반환 + 계약금의 10% |
| 공사 중 | 기지급금 반환 + 손해배상 |

---

## 4. 하자보수 기간 기준 (2023년 개정)

| 공종 | 하자담보 기간 |
|------|--------------|
| 방수 | **5년** (개정 전 3년 → 5년으로 강화) |
| 구조체 관련 | **5년** |
| 단열재 설치 | **3년** |
| 타일 시공 | **2년** |
| 도장, 도배 | **1년** |
| 전기, 설비 | **1년** |
| 가구 (붙박이) | **1년** |
| 기타 마감 | **1년** |

---

## 5. 분쟁 해결 단계

```
1단계: 당사자 간 협의 (자율 해결 우선)
    ↓ 협의 실패
2단계: 한국소비자원 피해구제 신청 (무료)
    ↓ 합의 안 됨
3단계: 소비자분쟁조정위원회 조정 신청
    ↓ 조정 불성립
4단계: 법원 소송 (소액사건심판 또는 민사소송)
```

---

## 6. 한국소비자원 접수 방법

- 온라인: www.kca.go.kr
- 전화: 1372 (소비자상담센터)
- 방문: 서울 수원 대전 대구 광주 부산 등 전국 지원

### 피해구제 신청 시 준비 서류
- [ ] 공사 계약서 사본
- [ ] 견적서 및 영수증
- [ ] 하자 사진 (날짜 포함)
- [ ] 하자 발생 경위서
- [ ] 시공사와 교환한 문자/메일 등

---

## 7. 분쟁 예방 체크리스트

| 항목 | 예방법 |
|------|--------|
| 계약 전 | 구두 약속 금지, 반드시 서면 계약 |
| 자재 확인 | 계약서에 브랜드·품번 명시 |
| 추가공사 | 구두 지시 금지, 추가공사 확인서 서명 |
| 공정 기록 | 공사일보·사진 보관 |
| 준공 | 검수 후 잔금 지급 |
| 하자 | 발견 즉시 서면 통보 (증거 보존) |
