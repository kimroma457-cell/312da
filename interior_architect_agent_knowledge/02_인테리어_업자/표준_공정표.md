# 표준 공정표

## 공정 순서 원칙

```
철거 → 설비/전기 배관 → 목공 → 방수 → 타일 → 도장/필름 → 바닥 → 가구 → 조명기구 → 청소 → 검수
```

> **핵심 선후관계**: 방수는 타일 전 필수 / 전기 배선은 석고 전 완료 / 바닥은 가구 전 시공

## 주요 선후관계 충돌 포인트

| 충돌 유형 | 위험 | 예방법 |
|-----------|------|--------|
| 전기 배선 미완료 → 석고 시공 | 배선 추가 불가 | 전기팀 확인 후 석고 |
| 방수 미완료 → 타일 | 누수 발생 | 방수 담수 테스트 필수 |
| 도장 전 바닥 → 오염 | 바닥 재시공 | 도장 완료 후 바닥 |
| 가구 설치 전 바닥 미완 | 가구 하부 마감 불량 | 바닥 완료 후 가구 |
| 실리콘 후 청소 미진 | 고객 불만 | 마지막 청소 철저 |
